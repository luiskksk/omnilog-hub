# OmniLog Hub — Definition of Done (DoD)

Uma tarefa será considerada concluída quando atender aos critérios aplicáveis abaixo.

## Critérios de conclusão
- [ ] A tarefa atende ao objetivo e aos critérios de aceitação definidos.
- [ ] O código segue a organização e o padrão adotados no projeto.
- [ ] Os dados de entrada são validados.
- [ ] As regras de negócio foram verificadas.
- [ ] Os testes aplicáveis foram executados e seus resultados registrados.
- [ ] Não existem erros conhecidos que impeçam a funcionalidade principal.
- [ ] A interface, quando aplicável, foi verificada em diferentes tamanhos de tela.
- [ ] Foram consideradas acessibilidade e proteção de dados.
- [ ] A documentação foi atualizada quando necessário.
- [ ] As alterações foram revisadas pelo próprio estudante.
- [ ] O commit possui mensagem clara e segue o padrão adotado.
- [ ] As alterações foram enviadas ao repositório remoto quando aplicável.

## Observações
- Nem todos os critérios se aplicam a tarefas exclusivamente documentais.
- Não marcar uma tarefa como concluída se houver falhas críticas pendentes.
- Por ser um projeto individual, a revisão será realizada pelo próprio estudante; a validação do professor será considerada quando disponível.
