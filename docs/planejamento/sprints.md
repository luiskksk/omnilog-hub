# OmniLog Hub — Planejamento das Sprints

## Metodologia
O projeto será organizado em quatro sprints de duas semanas, conforme a proposta inicial de Scrum. Como o trabalho é individual, o estudante será responsável pelo planejamento, desenvolvimento, testes e revisão.

## Sprint 1 — Planejamento e estrutura
**Objetivo:** definir a solução e preparar a base do projeto.

Atividades:
- Revisar o documento de visão.
- Documentar requisitos funcionais e não funcionais.
- Documentar casos de uso.
- Organizar o backlog.
- Criar o modelo inicial do banco de dados.
- Preparar a estrutura do repositório Git.

**Entrega esperada:** documentação inicial, backlog e estrutura organizada.

## Sprint 2 — Banco de dados e lógica
**Objetivo:** construir a base de dados e implementar regras essenciais.

Atividades:
- Finalizar o DER e o dicionário de dados.
- Implementar tabelas, chaves e restrições SQL.
- Inserir dados de teste.
- Implementar e testar regras de estoque.
- Desenvolver os primeiros algoritmos logísticos.
- Registrar testes e resultados.

**Entrega esperada:** banco estruturado e regras essenciais testadas.

## Sprint 3 — Aplicações e integração
**Objetivo:** desenvolver as interfaces e integrar as funcionalidades.

Atividades:
- Implementar a API com Node.js e Express.
- Criar a interface web com HTML, CSS e JavaScript.
- Desenvolver os cadastros prioritários.
- Implementar autenticação e controle de acesso.
- Desenvolver a aplicação desktop conforme a tecnologia definida.
- Integrar as aplicações ao banco de dados.

**Entrega esperada:** versão integrada com funcionalidades prioritárias.

## Sprint 4 — Testes e entrega
**Objetivo:** validar, corrigir e documentar a solução.

Atividades:
- Executar testes funcionais e de integração.
- Corrigir defeitos identificados.
- Verificar segurança, validação e acessibilidade.
- Revisar consultas e relatórios.
- Documentar instalação e utilização.
- Conferir commits, branches e repositório.
- Preparar a apresentação final.

**Entrega esperada:** versão validada, documentação revisada e apresentação preparada.

## Acompanhamento
Ao final de cada sprint, revisar o que foi concluído, registrar dificuldades e atualizar o backlog. As datas e o escopo deverão ser ajustados conforme o calendário real da atividade e as orientações do professor.
